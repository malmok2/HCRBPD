# 02 · 격자를 직접 지정하기

## 왜 직접 지정하나

이전에는 프로그램이 격자를 규칙으로 유도했습니다 — 목표 y+에서 첫 층을 잡고,
성장비 상한으로 반경 셀 수를 정하고, 단계마다 원주 셀 수를 1.45배씩 늘리는
방식이었습니다. 그 결과 **방향마다 세밀화 비율이 다른 사다리**가 만들어져
격자 수렴 지수(GCI)의 전제가 깨졌고, 원주 셀 수가 16~64개에 머물러
박리점을 잡을 수 없었습니다. 자세한 내용은
[05번 문서](05-지금까지-배운것.md)에 있습니다.

지금은 **격자를 사람이 정합니다.** 이 문서는 어떤 손잡이가 무엇을 하는지,
값을 얼마로 넣어야 하는지에 대한 참고서입니다.

## 영역 세 개

유동 방향으로 영역이 셋입니다.

```
   A 영역          B 영역 (번들)           C 영역
 ┌─────────┬──────────────────────────┬──────────────────┐
 │  입구   │  ○  ○  ○  ○  ○  ○  ○  ○  │      출구        │
 │  박스   │  ○  ○  ○  ○  ○  ○  ○  ○  │      박스        │
 └─────────┴──────────────────────────┴──────────────────┘
   L_in            n_rows × S_L              L_out
```

- **A · 입구 박스** — 균일 유입. 셀 수는 `nxIn`
- **B · 번들** — 봉 주위 O-grid. 여기가 격자의 본체
- **C · 출구 박스** — 유출 경계가 번들에 영향을 주지 않게 하는 완충. 셀 수는 `nxOut`

**Δp는 A와 C를 포함하지 않습니다.** 첫 봉 중심에서 반 피치 앞, 마지막 봉
중심에서 반 피치 뒤에 평면 두 장을 세우고 그 사이 압력차를 잽니다 —
상관식이 정의하는 방식 그대로입니다.

## 격자 손잡이 6개

### `nAz` — 봉 원주 격자

**봉 하나를 한 바퀴 도는 셀 수**입니다. 압력강하에 가장 크게 영향을 주는
값입니다. Δp는 봉 표면 압력분포(형상항력)가 지배하고, 그 분포는 박리점이
어디인지가 정하는데, 박리점을 찍으려면 원주 해상도가 있어야 합니다.

**요청값과 실제값이 다릅니다.** O-grid의 변마다 셀을 배분하기 때문에
반올림이 들어갑니다. 슬라이더 옆 화면에 **실제로 만들어지는 수**가
`→ 200 (변당 50)` 형태로 표시되므로 그것을 보세요.

정렬(in-line) 배열 — 실제값 = 8 × ceil(nAz/8), 즉 **8의 배수로 올림**:

| 넣은 값 | 실제 | | 넣은 값 | 실제 |
|---|---|---|---|---|
| 12 | 16 | | 60 | 64 |
| 14 | 16 | | 64 | 64 |
| 20 | 24 | | 96 | 96 |
| 29 | 32 | | 128 | 128 |
| 36 | 40 | | 200 | 200 |

→ **8의 배수로 넣으면 그대로 나옵니다.**

엇갈림(staggered) 배열 — 육각 셀의 여섯 변 길이가 달라 변마다 길이에
비례해 배분되므로 규칙이 단순하지 않습니다:

| 넣은 값 | 실제 | | 넣은 값 | 실제 |
|---|---|---|---|---|
| 12 | 12 | | 60 | 62 |
| 20 | 24 | | 96 | 100 |
| 32 | 36 | | 128 | 136 |

→ **엇갈림에서는 반드시 화면의 실제값을 확인하세요.**

**얼마로?** Δp가 목적이라면 16이나 64로는 부족합니다. 원주 128개면 셀당
2.8°, 256개면 1.4°입니다. 격자 민감도를 보려면 이 근처에서 시작해
위로 올리는 것이 맞습니다.

### `nRad` — 반경 격자

봉 표면에서 격자 여유(clearance)까지 O-grid를 채우는 **반경 방향 층 수**입니다.
clearance는 이웃 봉까지 절반 거리에서 반지름을 뺀 값이고, 화면 통계에
`벽면 여유`로 나옵니다.

`nRad`와 `firstLayer`가 함께 **성장비**를 결정합니다. 첫 층이 얇고 층 수가
적으면 성장비가 커집니다. 화면에 성장비가 표시됩니다 — **1.2 이하**를
권합니다.

### `firstLayer` — 첫 층 두께

벽에 붙는 첫 셀의 **높이**이며 **모델 단위(mm)**입니다. y+를 정하는 값입니다.

목표 y+에서 역산하는 식(프로그램이 쓰는 것과 같음):

```
c_f  = 0.079 · Re^(-1/4)            Blasius, Fanning
u_τ  = u_max · sqrt(c_f / 2)
y₁   = 2 · y⁺ · ν / u_τ             [m]
```

`2 ·`가 붙는 이유: y+는 **셀 중심**에서 정의되므로 셀 높이는 그 두 배입니다.

**직접 계산하지 않아도 됩니다.** 형상 탭의 `유동 조건` 칸에 속도·동점성·
밀도·목표 y+를 넣으면 `필요한 첫 층`이 나오고, **`첫 층에 적용`** 버튼으로
반영됩니다. 반대로 현재 첫 층에서 나오는 `현재 y+`도 같이 표시됩니다.

k-ω SST는 벽까지 적분하므로 **y+ ≈ 1**이 기준입니다. **y+ < 1은 해롭지
않습니다** — 격자 민감도 사다리를 만들 때 첫 층도 같이 줄이면 y+가 1 아래로
내려가는데, 그래도 됩니다. 오히려 첫 층을 고정해 두면 벽 근처가 전혀
세밀해지지 않아 GCI가 성립하지 않습니다.

### `nZ` — z 방향 층

폭 방향(스팬) 셀 수입니다. 위·아래가 대칭면이므로 **`nZ = 1~2`면 사실상
2차원**입니다. 상관식이 기술하는 무한 다발과 맞추려면 이쪽이 맞지만,
2차원에서는 와류가 스팬 방향으로 흐트러지지 않으므로 진동이 실제보다
강하게 유지됩니다. 3차원 효과를 보려면 `nZ`를 늘리고 채널 높이 H도 함께
키워야 합니다 (그리고 계산량이 그만큼 곱해집니다).

### `nxIn`, `nxOut` — A·C 영역 격자

입구/출구 박스의 유동 방향 셀 수입니다. 번들 쪽으로 갈수록 촘촘해지도록
분포가 들어가 있습니다. 여기가 거칠어도 Δp(번들 평면 기준)에는 직접
영향이 없지만, 입구 유동이 번들에 닿기 전에 왜곡되면 간접적으로 영향이
있습니다.

## 슬라이더보다 큰 값을 넣기

슬라이더 옆의 **숫자 칸에 직접 입력**하면 슬라이더 범위를 넘어서도
적용됩니다. 슬라이더 핀만 끝에 멈추고 값은 그대로 들어갑니다.
`nAz = 256`, `firstLayer = 0.00424` 같은 값이 그렇게 들어갑니다.

현재 슬라이더 범위 (숫자 칸은 제한 없음):

| 손잡이 | 슬라이더 범위 |
|---|---|
| `nAz` | 12 – 384 |
| `nRad` | 3 – 120 |
| `firstLayer` | 0.001 – 1.5 mm |
| `nZ` | 1 – 60 |
| `nxIn` | 2 – 240 |
| `nxOut` | 2 – 320 |

## 격자를 넣기 전에 볼 것 네 가지

형상 탭 아래 통계:

| 값 | 무엇을 보나 |
|---|---|
| **격자 수** | 계산 시간에 거의 비례합니다 |
| **최대 왜곡각** | 셀이 얼마나 찌그러졌나. 낮을수록 좋음 |
| **최대 AR** | 종횡비. 경계층 셀은 원래 크므로 큰 값 자체는 문제가 아님 |
| **벽면 여유** | clearance. `firstLayer × 성장비^nRad`가 이 값에 닿아야 함 |

그리고 **격자 표시** 모드를 `왜곡각` / `종횡비` / `셀 크기`로 바꿔 보면
어디가 나쁜지 색으로 보입니다.

## 격자 민감도 사다리를 손으로 만들 때

GCI(Celik 등 2008 / ASME V&V 20)를 쓰려면:

1. **최소 3단계** — 삼중항 하나가 필요합니다
2. **세밀화 비 r ≥ 1.3** — Celik 등의 권고
3. **모든 방향을 같은 비율로** — 이것이 핵심입니다. `nAz`, `nRad`, `nxIn`,
   `nxOut`을 r배 하면서 `firstLayer`는 **1/r배** 해야 합니다.
   한 방향이라도 고정하면 GCI가 여러 비율이 섞인 값을 읽습니다
   (프로그램이 이제 그것을 감지해 보고서에 빨간 경고로 띄웁니다)
4. `nRad`는 성장비가 1.2 이하로 유지되도록 함께 늘려야 합니다

r = 1.3, 3단계 예 (직경 10 mm, S = 15 mm, Re_max 1e4 기준):

| | `nAz` | `firstLayer` | y+ | `nRad` | `nxIn` | 셀 수 |
|---|---|---|---|---|---|---|
| L1 | 128 | 0.0318 | 1.00 | 19 | 40 | 약 222,000 |
| L2 | 168 | 0.0245 | 0.77 | 20 | 52 | 약 316,000 |
| L3 | 216 | 0.0188 | 0.59 | 22 | 68 | 약 459,000 |

(실제로 메싱해서 센 값입니다. 조건이 다르면 `firstLayer`부터 다시
계산해야 합니다.)
