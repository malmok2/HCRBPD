## 지금의 역할 분담

2026-09-17 이후:

- **격자와 해석 실행은 사용자가 직접** 합니다. 격자를 프로그램이 규칙으로
  자동 유도하게 맡긴 결과가 좋지 않았기 때문입니다 (자세한 이유는
  [05번 문서](05-지금까지-배운것.md)의 "격자 사다리" 항목).
- **결과 분석은 Claude가** 합니다. 무엇을 어떤 형식으로 넘기면 되는지는
  [04번 문서](04-결과-분석-의뢰.md)에 있습니다.
- **파라메트릭 탭은 그대로 둡니다.** 자동 캠페인이 필요해질 때 다시 쓸 수
  있도록 유지하되, 기본 작업 흐름은 아닙니다.

## 문서가 코드와 어긋나지 않게

`docs/` 안의 숫자는 손으로 적어 둔 것이 아닙니다. 코드에서 만들 수 있는
것은 전부 테스트로 다시 만들어 비교합니다:

```
python3 tests/docs_claims.py          # 약 1분 (격자를 실제로 만들어 셈)
python3 tests/docs_claims.py --quick  # 격자 생성 건너뛰기
```

Fluent도 라이선스도 필요 없습니다. **문서를 고치면 이것을 돌려 주세요** —
프로그램과 어긋난 안내서는 없는 안내서보다 나쁩니다.
