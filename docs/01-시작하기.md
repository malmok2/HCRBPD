# 01 · 시작하기

## 무엇을 하는 프로그램인가

봉 다발(rod bundle) 또는 나선 코일(helical coil) 횡유동의 **압력강하 Δp**를
구하고, 기존 상관식과 비교하는 도구입니다. 하나의 프로그램 안에서:

1. 형상을 파라미터로 만들고
2. 육면체(hex) 구조격자를 만들고
3. ANSYS Fluent를 띄워 풀고
4. Δp를 재고
5. 상관식과 비교해 보고서를 냅니다.

격자는 **닫힌 형태(closed form)**로 계산됩니다. 메싱 프로그램을 따로 돌리지
않으므로, 파라미터를 바꾸면 격자가 즉시 다시 그려집니다.

## 파일 구성

| 파일 | 무엇인가 |
|---|---|
| `mesh_explorer.html` | 화면 전부. 형상·격자·해석·결과·보고서·파라메트릭 6개 탭 |
| `mesh_explorer.py` | 격자 생성기의 파이썬 쌍둥이. 브라우저와 같은 격자를 만듭니다 |
| `app.py` | 로컬 서버. 브라우저와 Fluent 사이를 잇습니다 |
| `fluent_case.py` | PyFluent 드라이버. 케이스 설정·실행·측정 |
| `correlations.py` | 상관식 라이브러리 (1단계 결과물) |
| `zukauskas_charts.py` | Žukauskas 도표 4개를 수치화한 것 |
| `study.py` | 파라메트릭 캠페인 엔진 + 보고서 생성 |
| `studies/` | 캠페인 정의와 결과 |
| `runs/` | Fluent가 쓰는 격자·케이스 파일 (git에 올리지 않음) |

## 준비

```
pip install ansys-fluent-core
```

Fluent가 설치돼 있어야 실제 계산이 됩니다. 없어도 프로그램은 뜨고,
`MOCK` 백엔드로 화면과 배관만 확인할 수 있습니다 (그 숫자는 결과가 아니며
화면에 `MOCK`이라고 표시됩니다).

## 실행

```
cd C:\Users\user\HCRBPD
python app.py
```

브라우저가 `127.0.0.1`에 열립니다. 루프백 전용이라 외부에서 접속되지 않습니다.

옵션:

| 옵션 | 뜻 |
|---|---|
| `--port 8000` | 포트 지정 |
| `--backend mock` | Fluent를 쓰지 않고 배관만 확인 |
| `--backend fluent` | Fluent를 반드시 쓰라고 강제 |
| `--out-dir D:\runs` | 격자·케이스 파일을 쓸 폴더 |
| `--no-open` | 브라우저를 자동으로 열지 않음 |

**중요 · 두 가지**

1. **PowerShell 창을 닫으면 계산이 죽습니다.** 계산은 그 프로세스 안의
   스레드입니다. 브라우저는 닫아도 됩니다 — 다시 열면 진행 상황에 자동으로
   다시 붙습니다.
2. **코드를 `git pull` 한 뒤에는 서버를 다시 켜야 합니다.** 화면 오른쪽 위
   커밋 스탬프가 지금 돌고 있는 코드의 버전입니다. 바뀌지 않았으면 예전
   코드가 돌고 있는 것입니다. 작업 폴더에 커밋되지 않은 수정이 있으면
   스탬프가 주황색이 됩니다.

## 6개 탭

| 탭 | 하는 일 |
|---|---|
| **형상** | 치수·배열·격자 파라미터. 3D 형상과 단면 격자가 즉시 갱신됨 |
| **세팅** | Fluent 케이스 설정 (난류모형, 물성, 경계조건, 수치기법, 실행) |
| **해석** | 격자를 쓰고 Fluent를 띄워 계산. 잔차와 Δp가 실시간으로 그려짐 |
| **결과** | 유동장 컨투어. 스냅샷 저장/불러오기 |
| **보고서** | 이번 실행 하나에 대한 한 페이지 요약 |
| **파라메트릭** | 여러 케이스를 정의해 순서대로/동시에 돌리는 캠페인 |

## 한 번 돌려보기 — 처음부터 끝까지

**1. 형상 탭**

- 위쪽에서 형상을 고릅니다: `직선 rod · 정렬` / `직선 rod · 엇갈림` /
  `나선 코일 · 정렬` / `나선 코일 · 엇갈림`
- 치수: 직경 D, 횡피치 S_T, 종피치 S_L, 행 수, 열 수, 입구/출구 길이
- 격자: 자세한 것은 [02번 문서](02-격자-직접-지정.md)
- 아래 **격자 수 / 최대 왜곡각 / 최대 AR**을 확인합니다

**2. 유동 조건 (형상 탭 안)**

유입 속도, 동점성, 밀도, 목표 y+를 넣으면 **필요한 첫 층 두께**가 계산돼
나옵니다. **`첫 층에 적용`** 버튼을 누르면 격자에 반영됩니다.

**3. 세팅 탭**

기본값이 이 문제에 맞게 들어가 있습니다. 확인할 것:

- `정상/비정상` — 비정상(transient)이 기본입니다. [왜 그런지](03-해석-설정.md)
- 시간 간격·시간 스텝 수·평균 구간
- 코어 수 (기본 4)
- `케이스 파일 쓰기` — 나중에 유동장을 다시 보려면 켜 둡니다

**4. 해석 탭 → `시작`**

격자를 쓰고 Fluent를 띄우고 계산합니다. 잔차와 Δp가 실시간으로 그려집니다.

**5. 결과 · 보고서 탭**

컨투어를 보고, 보고서를 `HTML로 저장`합니다.

**6. 분석 의뢰**

[04번 문서](04-결과-분석-의뢰.md)를 보세요.
