# 06 · 현황과 미결

기준일: **2026-09-17**

## 프로그램의 목적

직선 봉 다발(정렬/엇갈림)의 압력강하를 기존 상관식과 비교하고, 이어서
나선 코일(정렬/엇갈림)로 넘어가, 최종적으로 **형상에서 새 상관식을
맞추는** 것입니다.

| 단계 | 내용 | 상태 |
|---|---|---|
| 1 | 상관식 수집·정리 | **완료** |
| 2 | 형상별 기본 격자 민감도 (물) | **재설계 필요** |
| 3 | 배열·조건에 따른 Δp 데이터 vs 상관식 | 미착수 |
| 4 | 코일 형상에 대해 상관식 개선 | 미착수 |

## 1단계 · 완료

`correlations.py`에 8개가 등록돼 있고, 그중 **4개는 계산 가능**합니다.

| 상관식 | 상태 |
|---|---|
| Jakob (1938) | 계산 가능 |
| Žukauskas (1972) | 계산 가능 (도표 4개를 `zukauskas_charts.py`로 수치화) |
| Gunter & Shaw (1945) | 계산 가능 |
| Shen 등 (2024), 나선 다발 | 계산 가능 |
| Gaddis & Gnielinski (1985) / VDI | **출처 필요** |
| Grimison (1937) | 출처 필요 |
| Idelchik, Handbook of Hydraulic Resistance | 출처 필요 |
| ESDU 79034 | 출처 필요 |

전부 **행당 Euler 수** 하나로 환산해서 비교합니다:

```
Eu_row = Δp_bundle / (N · ½ρu_max²)
```

- Jakob의 `Δp = 2fNρu_max²` → `Eu_row = 4f`
- Žukauskas의 `Δp = Nχf(ρu_max²/2)` → `Eu_row = χf`
- Shen 등의 `f` ≡ `Eu_row` (정확히 같음)

`u_max`는 가장 좁은 간극에서 나옵니다 — 횡방향 `S_T−d`와 면적 등가 대각
`2(S_D−d)` 중 작은 쪽, `S_D = √(S_L² + (S_T/2)²)`.

**측정된 밴드:** 네 상관식은 서로 **1.0~2.2배(보통 1.45배)** 차이 납니다.
"±20% 이내"가 아닙니다. 이 프로젝트가 존재하는 이유이기도 합니다.

**Žukauskas 도표 출처:** `ht` 1.2.0 (MIT)에서 가져와
`third_party/ht-LICENSE.txt`에 라이선스를 두었습니다. scipy 대비 최악
상대오차 2.33e-14로 검증했고, 원 문서의 예제 두 개를 정확히 재현합니다.
`ht`와 의도적으로 다른 점 하나: 어떤 도표를 쓸지는 **배열(정렬/엇갈림)**이
정하며 `S_T == S_L` 여부가 정하지 않습니다 — 헤더에 적어 두었습니다.

## 2단계 · 재설계 필요

한 번 돌렸고, **격자 설계 결함으로 결과를 쓸 수 없습니다.**

무엇이 나왔나 (rod-inline, X = 1.5, Re_max 1e4):

| | 셀 | 원주 셀 | Δp [Pa] | Eu_row |
|---|---|---|---|---|
| main-L1 | 13,504 | 16 | 2348 | 0.4659 |
| main-L2 | 24,576 | 24 | 1852 | 0.3675 |
| main-L3 | 38,784 | 32 | 1488 | 0.2953 |
| main-L4 | 71,712 | 48 | 1238 | 0.2457 |
| main-L5 | 119,808 | 64 | 1142 | 0.2266 |

단조 감소하고 증분도 줄어들지만(−21, −20, −17, −8%), **상관식 밴드
0.255~0.405를 관통해 아래로 나갔습니다.** 점근 영역에 들어가지 못했습니다.

두 가지 결함 — 자세한 진단은 [05번 문서](05-지금까지-배운것.md):

1. **원주 셀 수 16~64개.** 박리점을 찍을 수 없습니다
2. **방향마다 다른 세밀화 비** (원주 ×1.46, 반경 ×1.20, 벽면 수직 ×1.00).
   GCI의 전제가 깨졌고 관측 차수가 2.71 / 2.55 / 0.13으로 나왔습니다

**결정:** 격자를 자동 규칙에 맡기지 않고 **사람이 직접 지정합니다.**
방법은 [02번 문서](02-격자-직접-지정.md).

**이전 결과의 처지:** `studies/rod-inline-mesh/results.json`에 기록된
케이스들은 서로는 일관돼 있습니다(같은 조건, 같은 dt, 같은 스텝 수).
격자 간 상대 비교로는 의미가 있지만 **절대 Eu는 쓰지 않는 것이 맞습니다.**

## 3단계 · 미착수

정의는 만들어져 있습니다 — 배열당 30케이스:

- 피치비 X_T, X_L ∈ {1.25, 1.5, 2.0}
- Re_max ∈ {2e3, 1e4, 4e4, 1e5}
- 정렬·엇갈림 두 배열

2단계에서 격자가 정해진 뒤에 돌립니다. 격자를 손으로 정하기로 했으므로
이 정의의 격자 파라미터도 그때 손으로 넣어야 합니다.

## 4단계 · 미착수

나선 코일. Shen 등(2024) 식 (12)의 골격에 우리 데이터로 계수를 다시
맞춥니다:

```
Eu_row = (A/Re + B·Re^-m) · X_T^-p · X_L^-q · (cos ε)^-(c_K·K + c_0)
```

적합 코드(`correlations.fit_form`)는 이미 있고, **Shen의 계수를 1e-15까지
복원**하는 것으로 검증했습니다. 지수는 중첩 Nelder–Mead, 선형 계수는
닫힌 형태의 비음수 최소제곱입니다.

## 확정된 결정

| 항목 | 결정 | 근거 |
|---|---|---|
| 정상/비정상 | **비정상 (URANS)** | 정상해가 존재하지 않음 |
| 시간 간격 | 와류 주기 / 25 (St = 0.2) | |
| 계산 길이 | 다발 2회 통과 + 와류 15주기 | 플러싱은 다발 시계 |
| 시간 이산화 | 2차 음해법 우선, 설치본에 물어봄 | 1차는 측정 대상을 감쇠 |
| 답 | Δp의 **시간평균** | 순간값은 진동의 한 샘플 |
| 정착 판정 | 평균 이동 ≤ 1% (진폭 아님) | |
| 난류 | k-ω SST, y+ ≈ 1 | |
| 측벽 | 전부 symmetry | 무한 다발과 맞춤 |
| Δp 정의 | 첫·마지막 봉에서 반 피치 밖 평면 두 장 | 상관식 정의 |

| 병렬 | 케이스당 코어 적게, 동시에 여러 개 | 랭크당 5만 셀 손익분기 |
| 역할 | 실행은 사용자, 분석은 Claude | |

## 미결

1. **2단계 격자 사다리를 새로 설계** — 원주 해상도를 올리고 모든 방향을
   같은 비율로. 비용이 크므로 단계 수와 시작점을 정해야 합니다
   (r = 1.3, 3단계, 원주 128부터면 222k → 459k 셀)
2. **Gaddis–Gnielinski** — VDI Heat Atlas L1.4 자료가 필요합니다. 없어도
   밴드 검정은 나머지 4개로 됩니다
3. **2차원 vs 3차원** — 지금은 `nZ` 1~2로 사실상 2차원입니다. 실제 다발은
   스팬 방향으로 와류가 흐트러지므로, 수렴한 2차원 값이 상관식과
   체계적으로 다를 수 있습니다. 3차원 확인이 필요할 수 있습니다
4. **3단계 격자 파라미터** — 2단계가 끝난 뒤 정의에 손으로 넣어야 합니다
5. **나선 코일 형상 검증** — 4단계에 들어가기 전에 코일 격자를 따로
   확인해야 합니다 (펼쳐서 메싱한 뒤 되감는 구조)
