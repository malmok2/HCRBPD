# 04 · 결과를 분석에 넘기기

## 무엇을 넘기면 되나

**최소 하나만 있으면 됩니다.** 아래 중 위쪽이 정보가 많습니다.

### 1순위 · `results.json` (파라메트릭으로 돌린 경우)

```
studies/<연구이름>/results.json
```

케이스마다 이것이 다 들어 있습니다:

| 무엇 | 왜 필요한가 |
|---|---|
| `dp_bundle`, `eu_row` | 답 |
| `cells`, `h`, `nodes`, `skew_max`, `ar_max`, `volume` | 격자 |
| `D`, `ST`, `SL`, `n_rows`, `u_in`, `rho`, `nu`, `Re`, `XT`, `XL`, `umax` | 유동 상태 |
| `residual_history` (최대 400점) | 잔차 곡선의 **모양** |
| `dp_history` (최대 2000점) | Δp 이력 전체. 500스텝이면 하나도 안 버림 |
| `dp_spread`, `dp_mean_drift`, `dp_averaged_over` | 정착 판정 |
| `time_scheme`, `run_controls` | 실제로 무엇으로 돌았나 |
| `flowthroughs`, `flush_flowthroughs` | 다발을 몇 번 통과했나 |
| `converged`, `criterion`, `residual_worst`, `residual_worst_eq` | 잔차 판정 |
| `code`, `elapsed` | 코드 리비전, 소요 시간 |

**Δp 이력이 통째로 들어 있다는 것이 중요합니다.** 와류 이탈 주파수를
FFT로 확인하거나, 평균 구간을 다시 잡아 보거나, 정착 판정을 다시 하는 것이
전부 이 파일만으로 됩니다. **다시 돌릴 필요가 없습니다.**

### 2순위 · 보고서 HTML

보고서 탭 또는 파라메트릭 탭의 `HTML로 저장`. 숫자와 그림이 다 들어 있고
단독으로 열립니다. 다만 이력은 얇게 그려진 그림이라 재계산은 안 됩니다.

### 3순위 · CSV

파라메트릭 탭의 **`CSV로 내보내기`** → `studies/<이름>/history/<케이스>.csv`

케이스당 한 파일. 잔차와 Δp 이력을 공통 카운터로 묶은 표입니다.
Origin, Excel, matplotlib 어디서든 열립니다.

```
# case: main-L2
# transient - the counter is the time step
time_step,res:continuity,res:x-velocity,...,dp,dp_bundle
1,0.9355,0.3742,...,343.92,156.33
```

### 단발 실행(해석 탭)으로 돌린 경우

파라메트릭을 안 쓰고 해석 탭에서 하나만 돌렸다면 `results.json`이 없습니다.
그럴 때는:

- **보고서 탭 → `HTML로 저장`** — 이게 가장 간단합니다
- 또는 결과 탭의 **스냅샷 저장** (`.fields.json`) — 유동장 샘플까지 포함.
  솔버 없이 다시 열립니다

## 어떻게 넘기나

세션에 **파일을 그냥 올리면** 됩니다. 여러 개 한꺼번에도 됩니다.

같이 적어 주시면 분석이 정확해집니다:

1. **무엇을 물어보는지** — "격자 수렴했나" / "상관식과 얼마나 다른가" /
   "왜 이 케이스만 이상한가" 는 서로 다른 분석입니다
2. **격자를 어떻게 정했는지** — 특히 사다리를 만들었다면 단계마다 어떤
   손잡이를 얼마씩 바꿨는지. 방향별 세밀화 비가 분석의 핵심입니다
3. **직접 손댄 것** — 세팅 탭에서 기본값을 바꿨다면 무엇을

## `.cas.h5` 는 보내지 마세요

용량이 크고, **열려면 Fluent와 라이선스가 필요합니다.** 게다가 Fluent가
거기에 넣는 것은 **수렴된 場(field)**이고 거기까지 간 잔차 이력은 아닙니다.
분석에 필요한 것은 전부 `results.json`에 있습니다.

`.cas.h5`가 필요한 경우는 **유동장 그림을 다시 봐야 할 때뿐**입니다. 그건
교수님 PC에서 결과 탭의 `불러오기`로 여시는 게 맞습니다.

## 분석으로 무엇이 나오나

- **격자 수렴** — GCI (Celik 등 2008 / ASME V&V 20), 관측 차수, Richardson
  외삽, 방향별 세밀화 비가 균일한지 확인
- **상관식 대조** — Jakob, Žukauskas, Gunter–Shaw, Shen 등(2024) 4개를
  계산해 밴드를 만들고 CFD가 그 안에 드는지, 어디로 벗어나는지
- **정착 판정** — 진폭과 평균 이동을 구분해서, 답이 정말 멈췄는지
- **잔차 곡선 모양** — 평평한지(수렴할 대상이 없음) 아직 내려가는지
  (반복이 모자람). 고치는 방법이 다릅니다
- **상관식 적합** — Shen 등 식 (12) 골격에 우리 데이터로 계수를 다시 맞춤
  (4단계)
- **이상값 진단** — 한 케이스만 튀는 이유
